# Scriblark product screenshots

This continues the approved portfolio product-page work. Capture the existing,
qualified Store package on a fresh Windows runner. The application binary stays
unchanged; this is a separate marketing workflow and makes no new qualification
claim.

Use an original editable notebook, **A pocket of green**, about a fictional small
garden design workshop. A landscape page combines typed notes, pen sketches and
highlighted decisions. Capture the actual maximized editor, its saved Cornell
page template, and the actual exported PDF with the structural check result.
Keep all screenshots unaltered. Match product-page and Store captions to the
surfaces that were actually captured.

Implementation order:

1. Author the deterministic editable note and verify its structure and bounds.
2. Bind the capture downloader to one successful native run, exact unsigned MSIX,
   original readiness receipt and both original installation evidence sets.
3. Reuse reviewed native ownership, activation and input helpers; install a signed
   temporary copy, open the sample through the normal file chooser, save a named
   template, export and reopen the PDF. Record actual pixels, window identity,
   original package hashes and output file facts.
4. Close normally, uninstall, restore the display and remove only owned temporary
   data and certificates. Retain screenshots and receipts, never signing keys.
5. Review the original Windows images, update the website and Store listing,
   verify canonical HTTPS pages, and submit the unchanged qualified package.

An unsuccessful or unbound native package may not be used for public marketing.
